1.Python

  • Python is a high-level, interpreted, general-purpose programming language.
  • It was designed to be simple and easy to learn.
  • Python uses easy-to-read syntax, similar to the English language.
  • It supports object-oriented, procedural, and functional programming.
  • Python is open-source and free to use.

    • 2.History of Python


  • 1989: Python was created by Guido van Rossum in the Netherlands.
  • 1991: The first public version, Python 0.9.0, was released.
  • 1994: Python 1.0 was released.
  • 2000: Python 2.0 was released with several improvements.
  • 2008: Python 3.0 was released with major changes to the language.
  • 2020: Official support for Python 2 ended.
  • Today: Python 3 is the actively maintained version and is widely used around the world.

    • 6.Data Types


    In Python, data types specify the type of value a variable stores. Python has several built-in data types.

    1. Integer (int)
      2. Stores whole numbers.
      eg.
      a = 10
      b = -5
      print(type(a))

    2. Float (float)
      3. Stores decimal numbers.
      eg.
      x = 3.14
      y = 5.5
      print(type(x))

    3. String (str)
      4. Stores text inside quotes.
      eg.
      name = "Amit"
      city = 'Pune'
      print(type(name))

    4. Boolean (bool)
      5. Stores `True` or `False`
      eg.
      is_student = True
      print(type(is_student))

    5. List (list)
      6. Stores multiple items in square brackets. Lists are changeable.
      eg.
      numbers = [10, 20, 30]

    6. Tuple (tuple)
      7. Stores multiple items in parentheses. Tuples cannot be changed after creation.
      eg.
      colors = ("red", "blue", "green")

    7. Dictionary (dict)
      8. Stores data as key-value pairs.
      eg.
      student = {"name": "Amit", "age": 16}

    8. Set (set)
      9. Stores unique items, without duplicates.
      eg.
      values = {1, 2, 3, 3}
      print(values)

    9. None (NoneType)
      10. Represents the absence of a value.
      eg.
      result = None
      print(type(result))

    7.Control Statements


    Control statements are statements that control the flow of execution of a program. They determine which statements execute, how many times they execute, and when execution stops or skips ahead.

    Python control statements are commonly grouped into three categories:
    1. Conditional Statements
      2. These execute code based on a condition.

      1. 'if' statement
        2. Executes code when a condition is true. eg. 
        age = 18
if age >= 18:
    print("You are an adult")
        Output: You are an adult

      2. 'if-else' statement
        3. Chooses between two alternatives.
        eg. 
        num = 7
if num % 2 == 0:
    print("Even number")
else:
 print("Odd number")
        Output: Odd number

      3. 'if-elif-else' statement
        4. Checks multiple conditions.
        eg. 
        marks = 75
if marks >= 90:
    print("Grade A")
elif marks >= 60:
   print("Grade B")
else:
   print("Grade C")
        Output: Grade B

    2. Looping Statements
      3.  Loops execute a block of code repeatedly.
      1. 'for'loop
        2. Used to iterate over a sequence or other iterable.
        eg. 
        for i in range(1, 6):
    print(i)

Output:
1
2
3
4
5

      2. 'while' loop
        3. Repeats as long as its condition remains true.
        eg. 
        i = 1
while i <= 3:
    print(i)
    i += 1

Output:
        
1
2
3
    3. Jump Statements
      4. Jump statements alter the normal flow of execution within loops.
      1. 'break
        2. Terminates the nearest enclosing loop.
        eg. 
        for i in range(1, 6):
    if i == 3:
        break
    print(i)

Output: 1 2

      2. 'continue'
        3. Skips the current iteration and proceeds to the next one.
        eg. 
        for i in range(1, 5):
    if i == 3:
        continue
    print(i)

Output: 1 2 4

      3. 'pass'
        4. Does nothing; it acts as a placeholder where a statement is syntactically required.
        eg. 
        for i in range(3):
    pass

print("Done")

Output: Done

    Quick revision table

    Statement Purpose
    if Checks a condition
    if-else Selects between two alternatives
    if-elif-else Selects among multiple alternatives
    for Iterates over a sequence
    while Repeats while a condition is true
    break Exits a loop
    continue Skips to the next iteration
    pass Acts as a placeholder

    8. File Handling in Python


    File handling in Python allows you to create, open, read, write, append, and close files. It is useful for storing data permanently so that it remains available even after a program finishes running.
    1. Opening a file
      2.  Python uses the 'open()' function to open a file.
      Syntax:
      file = open("filename.txt", "mode")
      The mode specifies what you want to do with the file.



      Mode Description
      "r" Read a file
      "w" Write to a file (creates or overwrites it)
      "a" Append data to a file
      "x" Create a new file; fails if it exists
      "r+" Read and write
      "b" Binary mode, e.g. "rb"
      "t" Text mode (default)

    2. Reading a file
      3.  Suppose 'demo.txt'contains:
      text:
      Hello Python!
      Welcome to file handling.

      Example 1: Read the entire file f = open("demo.txt", "r")
      content = f.read()
      print(content)
      f.close()
      Output: Hello Python!
      Welcome to file handling.

      Example 2: Read one line f = open("demo.txt", "r")
      print(f.readline())
      f.close()
      Output: Hello Python!

      Example 3: Read all lines 
      f = open("demo.txt", "r")

for line in f:
    print(line, end="")

f.close()
      This reads the file line by line.

    3. Writing to a file
      4.
      The "w" mode creates a file if it doesn't exist. If the file already exists, its old contents are overwritten.

      f = open("demo.txt", "w")
      f.write("Hello World!")
      f.close()
      The file now contains:
      Hello World!

    4. Appending to a file
      5.
      The "a" mode adds new content at the end without removing existing content.

      f = open("demo.txt", "a")
      f.write("\nWelcome to Python.")
      f.close()

      The file now contains:
      Hello World!
      Welcome to Python.

    5. Using 'with' to handle files
      6.
      The recommended approach is to use the `with` statement. It automatically closes the file, even if an error occurs.
      with open("demo.txt", "r") as f:
    content = f.read()
    print(content)
      Advantages:
      - Automatically closes the file.
      - Makes code cleaner and safer.
      - Reduces the chance of resource leaks.

    6. Creating a file
      7.
      You can create a new file using `"x"` mode.
      with open("newfile.txt", "x") as f:
    f.write("This is a new file.")
      If 'newfile.txt' already exists, Python raises a 'FileExistsError'.

    7. Useful file methods
      8.

      Method Purpose
      read() Reads the entire file or a specified number of characters
      readline() Reads one line
      readlines() Returns all lines as a list
      write() Writes a string to a file
      writelines() Writes multiple strings from an iterable
      seek() Moves the file cursor to a position
      tell() Returns the current cursor position
      close() Closes the file


      Example using 'tell()' and 'seek()':
      with open("demo.txt", "r") as f:
    print(f.tell())  
    print(f.read(5)) 
    print(f.tell())  
    f.seek(0)        
    print(f.read(5))


    8. Handling file errors
      9.
      Use 'try-except' to handle errors such as a missing file. 
      try:
    with open("missing.txt", "r") as f:
        print(f.read())
except FileNotFoundError:
    print("File does not exist.")
Output:
File does not exist.


    9. Practical example: Write and read a file
      10.  
      # Write data
with open("student.txt", "w") as f:
    f.write("Name: Rahul\n")
    f.write("Marks: 85\n")

# Read data
with open("student.txt", "r") as f:
    print(f.read())

Output:
Name: Rahul
Marks: 85
