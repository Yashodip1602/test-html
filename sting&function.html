Strings

1. What is a String?

  • A string is a sequence of characters enclosed in single quotes (' ') or double quotes (" ").
    • name = "Python"
city = 'Mumbai'
print(name)
print(city)

Output:
Python
Mumbai

    2. String Concatenation

  • Concatenation means joining two or more strings using the '+' operator.
    • a = "Hello"
b = " World"
print(a + b)

Output:
Hello World

    3. String Repetition

  • The '*' operator repeats a string a specified number of times.
    • word = "Hi "
print(word * 3)

Output:
Hi Hi Hi

    4. String Indexing

  • Indexing is used to access individual characters in a string.
  • Python indexing starts from '0'.
    • s = "Python"
print(s[0])
print(s[2])
print(s[-1])

Output:
P
t
n
  • s[0] accesses the first character.
  • s[2] accesses the third character.
  • s[-1] accesses the last character.

    • 5. String Slicing

  • Slicing is used to extract a part of a string.
  • Syntax: 'string[start:end]'
  • The starting index is included, but the ending index is excluded.
    • s = "Python"
print(s[0:3])
print(s[2:6])

Output:
Pyt
thon

    6. Finding the Length of a String

  • The 'len()' function returns the total number of characters in a string, including spaces.
    • s = "Hello"
print(len(s))

Output:
5

    7. Important String Methods

  • String methods are built-in functions used to perform operations on strings.

    • Method Purpose Example
    upper() Converts to uppercase "hello".upper() → "HELLO"
    lower() Converts to lowercase "HELLO".lower() → "hello"
    title() Capitalizes each word "hello world".title() → "Hello World"
    capitalize() Capitalizes the first character "python".capitalize() → "Python"
    strip() Removes surrounding whitespace " hi ".strip() → "hi"
    replace() Replaces part of a string "cat".replace("c", "b") → "bat"
    count() Counts occurrences "banana".count("a") → 3
    find() Finds the first position "python".find("t") → 2
    split() Splits a string into a list "a,b,c".split(",") → ['a', 'b', 'c'] 

    Example:
text = "hello python"
print(text.upper())
print(text.replace("python", "world"))

Output:
HELLO PYTHON
hello world

    8. Checking a String with 'in'

  • The 'in' operator checks whether a character or substring exists in a string.
    • s = "Python Programming"
print("Python" in s)
print("Java" in s)

Output:
True
False

    9. Reversing a String

  • You can reverse a string using slicing with '[::-1]'.
    • s = "Python"
print(s[::-1])

Output:
nohtyP

    10. String Formatting Using f-Strings

  • F-strings allow you to insert variables directly into a string.
    • name = "Rahul"
age = 16
print(f"My name is {name} and I am {age} years old.")

Output:
My name is Rahul and I am 16 years old.

    11. Strings Are Immutable

  • In Python, strings are immutable, which means their individual characters cannot be changed directly after the string is created.
    • Incorrect example:
s = "cat"
s[0] = "b"

This produces a "TypeError".

Correct approach:
s = "cat"
s = "b" + s[1:]
print(s)

Output:
bat

The code creates a new string instead of modifying the original string.

    Functions

  • A function in Python is a block of code that performs a specific task. You can reuse a function whenever you need it instead of writing the same code again and again.

    • 1. Types of Functions in Python

    There are two main types of functions:
  • Built-in functions — already provided by Python.
  • User-defined functions — created by the programmer using the 'def' keyword.

    • 2. Built-in Functions

  • Python provides many built-in functions to perform common tasks.

    • Function Purpose Example
    print() Displays output print("Hello")
    input() Takes input from the user input("Enter name: ")
    len() Returns the length len("Python") → 6
    type() Returns the data type type(10) → int
    int() Converts to an integer int("5") → 5
    float() Converts to a decimal number float("2.5") → 2.5
    str() Converts to a string str(100) → "100"
    max() Returns the largest value max(2, 8, 4) → 8
    min() Returns the smallest value min(2, 8, 4) → 2
    sum() Adds values in an iterable sum([1, 2, 3]) → 6
    abs() Returns the absolute value abs(-7) → 7
    round() Rounds a number round(3.14159, 2) → 3.14 

    Example:
numbers = [10, 20, 30]
print(len(numbers))
print(max(numbers))
print(sum(numbers))

Output:
3
30
60

    3. User-Defined Functions

  • A user-defined function is a function created by the programmer to perform a particular task.
    • Syntax: def function_name(): # statements pass
  • 'def' is the keyword used to define a function.
  • 'function_name' is the name of the function.
    • The parentheses `()` may contain parameters. The indented statements form the function body. 
    Example:
def greet():
    print("Hello, welcome to Python!")
greet()

Output:
Hello, welcome to Python!
  • The function runs when we call it using 'greet()'.

    • 4. Functions with Parameters

  • Parameters allow you to pass information into a function.
    • def greet(name):
    print("Hello", name)
greet("Rahul")
greet("Priya")

Output:
Hello Rahul
Hello Priya
  • Here, "name" is a parameter, while "Rahul" and "Priya" are arguments passed to the function.

    • 5. Functions with a Return Value

  • The "return" statement sends a result back to the code that called the function.
    • def add(a, b):
    return a + b
result = add(10, 20)
print(result)

Output:
30
  • The function adds two numbers and returns their sum.

    • 6. Types of User-Defined Functions Based on Arguments and Return Values

    Type Description
    No arguments, no return value Takes no input and returns no result.
    Arguments, no return value Takes input but does not return a result.
    No arguments, return value Takes no input but returns a result.
    Arguments and return value Takes input and returns a result. 

    Example of a function with arguments and a return value:

def square(number):
    return number * number
print(square(5))

Output:
25

    7. Default Arguments

  • A default argument is a parameter that has a predefined value.
  • Python uses it when no argument is provided for that parameter.
    • def greet(name="Friend"):
    print("Hello", name)
greet()
greet("Aman")


Output:
Hello Friend
Hello Aman

    8. Lambda Functions

  • A lambda function is a small anonymous function written using the "lambda" keyword.
  • Lambda functions are useful for short operations.
    • square = lambda x: x * x
print(square(4))

Output:
16

    9. Advantages of Functions

  • Code reusability: Write code once and use it multiple times.
  • Less repetition: Avoid writing the same code repeatedly.
  • Easy debugging: Find and fix errors more easily.
  • Better organization: Divide a large program into smaller parts.
  • Easy maintenance: Make changes in one place when possible.
