1.Math


- The Math Library is a built-in Python library used to perform mathematical calculations.

- It provides functions for square roots, powers, factorials, rounding numbers, and other mathematical operations.

Uses: Scientific calculations, solving mathematical problems, and performing numerical operations.
Syntax: import math

Important functions

Function Use Example output
math.sqrt(25) Square root 5.0
math.pow(2, 3) Power 8.0
math.ceil(4.2) Round up 5
math.floor(4.8) Round down 4
math.factorial(5) Factorial 120
math.pi Value of pi 3.14159.... 

eg.
import math
print(math.sqrt(16))
print(math.factorial(4))

Output:
4.0
24

2.DateTime

- The Datetime Library is a built-in Python library used to work with dates and times.

- It helps us get the current date and time, calculate time differences, and format dates.

Uses: Managing dates, scheduling events, calculating age, and handling time-related operations.

Important functions

Function Use
datetime.now() Gets the current date and time
date.today() Gets today's date
strftime() Converts date/time into formatted text
timedelta() Adds or subtracts time 
 eg.1:

import datetime
print(datetime.datetime.now())

Output (example):
2026-10-17 13:18:00

eg 2: Today's date

import datetime
print(datetime.date.today())

Output (example):
2026-10-17

3.OS

- The OS Library is a built-in Python library used to interact with the operating system.

- It helps manage files, folders, directories, and system-related tasks.

Uses: Creating folders, listing files, renaming files, deleting files, and getting the current working directory.

Important functions

Function Use
os.getcwd() Gets the current directory
os.mkdir() Creates a new folder
os.listdir() Lists files and folders
os.remove() Deletes a file
os.rename() Renames a file 

eg.
import os
print(os.getcwd())

Output (example):
/home/user

This displays the current working directory.

4.NumPy

- NumPy stands for Numerical Python.

- It is a Python library used for numerical calculations and working with arrays.

- It performs mathematical operations on large amounts of data efficiently.

Uses: Array operations, mathematical calculations, scientific computing, and data analysis

Important functions

Function Use
np.array() Creates an array
np.mean() Calculates the average
np.max() Finds the maximum value
np.min() Finds the minimum value
np.sum() Calculates the sum 

eg.
import numpy as np
numbers = np.array([10, 20, 30, 40])
print(np.sum(numbers))
print(np.mean(numbers))

Output:
100
25.0

5.Pandas

- Pandas is a Python library used to organize, manipulate, and analyze data.

- It provides data structures such as Series and DataFrame to work with tabular data.

Uses: Data analysis, handling CSV and Excel files, organizing data, and cleaning datasets

Important functions

Function Use
pd.DataFrame() Creates a table
pd.read_csv() Reads a CSV file
df.head() Displays the first 5 rows
df.describe() Shows statistical information
df.drop() Removes rows or columns 

eg.
import pandas as pd
data = {
    "Name": ["Amit", "Priya"],
    "Age": [20, 22]
}
df = pd.DataFrame(data)
print(df)

Output:
    Name  Age
0   Amit   20
1  Priya   22
